## V275 — KO_FULL_SENTENCE_GRAMMAR_FLATTENING_V1 design disposition

Status: CANONICAL DESIGN DIRECTION

The selected Korean design rule is:

`preserve dynamic meaning / flatten inherited Japanese dynamic grammar`

Required semantic buckets:

```text
GRAMMAR_FLATTEN
DYNAMIC_MEANING_RETAIN
MIXED_SPLIT_REQUIRED
UNRESOLVED
```

A grammar family is not globally blanked first. Required order is full caller census,
semantic/branch classification, caller-level Korean sentence migration, residual caller
accounting, and only then possible retirement of an unused grammar literal family.

Global repeated-syllable dedup, suffix deletion, forced predicate values, global
speech-style inversion, and C73/C188 local first-syllable stripping remain rejected.

This design adds no WRITE_SAFE authority.

## V279 — Adversarial speech-style ownership review

Status: PASS / REVISED DESIGN CONTRACT

All 42 grammar families carry multiple Korean output/register variants rather than one
fixed output. Observed family output multiplicity spans roughly 2–9 variants, with
representative examples including:

```text
C73   입니다 / 이오 / 이다 / 이네 / 이옵니다 ...
C188  하겠습니다 / 하겠다 / 합니다 / 한다 / 하오 ...
C209  없습니다 / 없소 / 없네 / 없다 / 없사옵니다 / 없어요 ...
```

`0x6A` remains a real speech-style selector. Global inversion remains rejected.

Among all 1,013 grammar callers:

```text
caller contains direct 0x6A style branch      601 / 1,494 grammar edges
caller has no direct 0x6A style branch        412 /   870 grammar edges
```

The former 913 structurally-direct callers therefore split into:

```text
CALLER_STYLE_BRANCH_AVAILABLE       567 callers / 1,356 grammar edges
STYLE_COLLAPSE_REVIEW               346 callers /   731 grammar edges
TOTAL                               913 callers / 2,087 grammar edges
```

The earlier assumption that all 913 could proceed as automatic/direct migration is
rejected. The 567 callers are the preferred first detailed matrix because their caller
already owns explicit style/control branching that can be preserved while grammar
segmentation is flattened. The 346 callers require explicit review of register/tone
loss before a nested formatter dependency may be removed.

## V280 — Composition-coupling and morphology review

Status: PASS / LOWER-BOUND RISK CENSUS

A simple Korean-literal adjacency scan around the 2,364 grammar edges found:

```text
left-side stored overlap present        604 edges
right-side Hangul continuation present  728 edges

left only                                458
right only                               582
both                                     146
neither                                1,178
```

Therefore at least 1,186 grammar edges across 601 callers are directly
composition-coupled by these simple visible conditions.

This is a lower-bound shape census, not a safe/unsafe rewrite classifier. Korean
morphology can overlap without identical adjacent syllables. Representative C109 forms
such as `했습니다 / 했다 / 했사옵니다 / 했어요` can be called after caller stems/forms
such as `기다리셨`, `기다렸`, or `실패했`. Raw byte/syllable dedup therefore misses real
responsibility collisions.

Disposition: prefix/suffix trimming, repeated-syllable cleanup, or a fixed boundary rule
cannot replace caller-level Korean full-sentence responsibility migration.

## V281 — Adversarial-review canonical disposition and STOP boundary

Status: CLOSED / NEXT READ_ONLY

The core design remains:

`preserve dynamic meaning / flatten inherited Japanese dynamic grammar`

The migration contract is strengthened to:

1. preserve caller control/branch skeleton;
2. preserve required dynamic semantic call IDs/order;
3. flatten inherited Japanese grammar segmentation into branch-local natural Korean;
4. never collapse nested formatter register/tone implicitly;
5. require explicit `STYLE_COLLAPSE_REVIEW` or `TONE_CRITICAL_EXCEPTION` disposition
   when caller-local control does not already preserve the needed distinction;
6. treat SC/TW only as proof of engine-compatible structural flattening, not as a
   Korean tone/register oracle.

Current first detailed-matrix scope:

`KO_GRAMMAR_FLATTEN_CALLER_STYLE_BRANCH_AVAILABLE_567_MATRIX_READ_ONLY`

That scope is analysis only. It may enumerate and design the 567 caller-level migration
matrix, but it does not authorize Korean text mutation, TAI5MSG rewriting, builder
implementation, diagnostic build, IPS generation, runtime patching, or new WRITE_SAFE.

A fresh explicit user execution signal is required before beginning that 567-caller
matrix.
